## Processing

Each source was downloaded at 2400 px wide, cropped with attention-based
cropping to the aspect ratio used by its slot, gently desaturated
(saturation 0.95), lightly sharpened and exported as WebP (quality 82) at
1600–2000 px wide. Original generated placeholders are backed up outside the
project.

## Replacing with real photography

1. Export each photo at 1600 px wide or larger in the same aspect ratio as the
   slot: 4:5 for hero, products, stories and about; 4:3 for services; 16:9 for
   blog posts; 5:4 for approach; 16:10 for workshop.
2. Save as WebP with the same filename in this folder.
3. Update this file with the new photographer/source, or delete the row.
4. Keep the subjects free of identifiable people unless you have a signed model
   release from the person photographed.
